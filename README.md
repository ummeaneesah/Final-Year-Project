# Final-Year-Project
Title: Supplement Scheduler

Original Dataset :
https://api.ods.od.nih.gov/dsld/s3/data/DSLD-full-database-XLSX.zip

This data came from the National Institute of Health (USA) https://dsld.od.nih.gov/api-guide 

Description:

This project is about creating a Supplement Scheduler website that can be implemented into our daily routines as it addresses a common yet overlooked problem faced by individuals who take supplements. Trying to determine how much, how often, and when to take supplements safely and effectively is hard to glean from text-heavy product labels. This can lead to incorrect dosing, poor adherence, or unsafe combinations. It becomes even more complex with the multiple forms of supplements like tablets, capsules, liquids, and powders with different usage instructions. This is where scheduling becomes necessary to achieve a more efficient supplement intake. 

The Tools:

Excel - Storing the dataset as an excel file so it can be run in the python code. Cleaning the features of the dataset in the excel file. Using filters to look through the datasets formatting.  

Python - Coding using python language when developing the model that the website will be run on. Testing the data accuracy and system output. 

Github Repository - Uploading different materials used in the making of this project into a GitHub repository to keep track of the project as well as keep record of the project to use as a portfolio.
